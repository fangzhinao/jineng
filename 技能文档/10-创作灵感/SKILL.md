# 创作灵感

给房产人出**能直接拍**的选题，不是「分享你的购房经验」这种废话。

**这是纯提示词技能，不需要调 API。**（想更准可以配合「账号数据分析」技能看他自己的号）

## 触发场景

- 「不知道拍啥」「没选题了」
- 「给我几个选题」「创作灵感」
- 「最近拍什么好」
- 「我的号接下来该拍什么」

---

## 核心原则（写给自己看）

**房产人的选题只有两种真正能获客：**

```
A. 楼盘分析型 ——「XX 楼盘到底能不能买」
B. 预算选房型 ——「预算 X 万，能买哪些 / 该选哪里 / 新房还是二手」
```

**其他都是补充。**

**判断一个选题好不好，就问一句：**
```
看完这条，客户会不会想问「那我这套能买吗」？
不会 → 这选题不获客，是自嗨
```

---

## 三条铁律

```
① 标题必须能直接当视频标题用
   ✅「郴州 100 万，新房和二手选哪个？」
   ❌「关于预算选房的一些建议」

② 至少 2 条要结合本地 + 具体楼盘/价格
   全是空泛话题 = 跟 AI 生成的没区别

③ 每条都要说清「为什么建议你拍这条」
   不是列表，是诊断
```

**绝对不要给的选题：**
```
❌「分享你的购房经验」
❌「聊聊市场行情」
❌「介绍一下你的工作日常」
❌「如何做好服务」
❌「给购房者的建议」
```
**这些谁都能说，说了也没人看。**

## 执行流程

### 情况一：用户给了抖音主页链接

**先调「账号数据分析」技能，拿到他的作品列表，再诊断。**

```
① 解析主页链接 → sec_user_id
② 拉账号信息 + 近 10~20 条作品
③ 分析（这一步最重要，不要跳过）：
   · 近 10 条标题分别在讲什么
   · 有没有重复套路（连续 5 条都在探盘？）
   · 哪类题材数据好（点赞/评论高的是哪些）
   · 哪类没人看
   · 缺什么：
     - 只有探盘没有干货？
     - 只有房源没有观点？
     - 只有硬广没有人设？
     - 有干货但开头太慢？
   · 更新节奏（一周几条？最近断更了没）
   · 标题写法（是不是都很平？有没有钩子？）
④ 给 5 条选题（格式见下）
```

### 情况二：用户没给链接

**不要硬要。先说这句：**

```
「我看你还没给我账号链接。
 有链接我能看着你的号给建议，更准；
 没有也行，我先按【你的城市】给你几条通用的。
 要发链接的话：抖音 App → 我的 → 右上角分享 → 复制链接」
```

**然后按「通用三方向」给。**

### 情况三：用户说了具体方向

**比如「我想拍学区房」「我想讲预算选房」—— 直接按那个方向给 5 条，别反问。**

## 输出格式（严格按这个）

```
💡 给你 5 条选题

---

**1. 【郴州 100 万，新房还是二手？】**
为什么建议拍：你近 10 条全是探盘，一条讲选择的都没有。这类「帮客户做决定」的内容最容易私信。
怎么拍：站你门店门口，开头直接说「100 万在郴州，我劝你先别急着买新房」。

**2. 【北湖区这 3 个盘，哪个最抗跌？】**
为什么建议拍：你数据最好那条（412 赞）就是楼盘对比。这个题材你能拍好，可以再做一个更聚焦的。
怎么拍：三个盘的售楼部门口各拍 5 秒，回来剪，开头先说结论再说理由。

**3. ...**

**4. ...**

**5. ...**

---

这 5 条里我最推荐第 1 条，因为你现在最缺的不是曝光，是「让人愿意私信你的理由」。

想拍哪条？我可以直接把口播稿给你写出来。
```

**每条必须有三样：标题 + 为什么 + 怎么拍。**

## 通用三方向（没账号数据时用）

**给三个方向各 2 条，共 6 条：**

### 方向一：本地热点

```
· 【郴州 {最近交付的小区}，交房现场我去了】
· 【郴州这次土拍，对你手上的房子有什么影响】
· 【{新政策} 出台后，我在郴州跑了 3 个售楼部】
```

**要点：必须是本地真实事件，不是全国性政策。**

### 方向二：客户常问问题

```
· 【郴州首套，新房二手怎么选？我拆成 3 个问题】
· 【公积金能贷多少？在郴州我帮客户算过 20 次】
· 【二手房砍价，我教客户只说了两句话】
· 【预算 80 万在郴州，能买哪儿？我把范围缩到 3 个片区】
```

**要点：用「我帮客户做过」的语气，不是「你应该」。**

### 方向三：手上房源实拍

```
· 【我手上这套 {小区}，有个别人没注意的优点】
· 【这套房挂了 8 个月没卖掉，我知道为什么】
· 【{小区} 89 平 vs 118 平，差价 30 万差在哪】
```

**要点：必须问用户「你手上现在有哪几套」，用真实房源。**

## 五种「缺口诊断」（最重要的部分）

**拿到他的作品列表后，对照这五种缺口，缺哪种就补哪种：**

| 缺口 | 症状 | 该补什么 |
|---|---|---|
| **只有探盘，没有观点** | 全是「带你看房」，没有「我觉得」 | 讲判断：哪个盘值、哪个不值 |
| **只有房源，没有干货** | 全是房子，没有方法论 | 讲知识：首套怎么选、政策怎么用 |
| **只有硬广，没有人设** | 全是「这套房抓紧」，没有「我是谁」 | 讲自己：本地人、做几年、我的原则 |
| **有干货，没有钩子** | 内容不错但开头慢、标题平 | 改开头：前 3 秒给数字/冲突 |
| **断更 / 节奏乱** | 最近一条一个月前 | 先恢复周更，再谈质量 |

**诊断出来要明确说：**
```
「你的号现在最大的问题不是选题，是**全是探盘没有观点**。
 观众看完知道你带看，但不知道你怎么判断。
 所以我这 5 条里有 3 条是讲判断的。」
```

## 一条选题的价值判断（自己用）

**拿到一个候选选题，问四个问题：**

```
① 这条能吸引谁？ （说不出具体人群 = 废）
   ✅「预算 100 万的首套刚需」
   ❌「想买房的人」

② 看完他会做什么？
   ✅ 私信问「我那套能买吗」
   ❌ 「哦，挺好」

③ 别人能拍吗？
   能拍 = 同质化。要找「只有本地人/只有我能拍」的角度

④ 需要什么数据？
   需要真实价格的，先确认用户有没有
```

## 错误处理

| 情况 | 怎么做 |
|---|---|
| 用户没给城市 | 问一句「你在哪个城市？」，或者从账号签名里读 |
| 用户没账号链接 | 给通用三方向，别硬要 |
| 拉不到账号数据 | 用通用三方向，并说明「拿不到你的号，先给通用的」 |
| 用户说「这些都太普通」 | 问「你想要什么样的方向？」，然后按他说的再出 5 条 |
| 用户说「就这些？」 | 说明思路：「再多也是这几类，关键是选一条拍起来」 |

## 一句话记住

```
好选题 = 具体人群 + 他能做的决定 + 只有你能给的信息
```

**缺任何一个，都是自嗨。**
