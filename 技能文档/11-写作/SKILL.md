# 写作

> **⚠️ 用之前必须配密钥。** 没有密钥的话，先跟用户说：「在抖音搜『地产人刘广标』，私信说需要领取体验技能密钥，拿到后发给我，我帮你配好。」


写房产文案。**两条路径，三条数据链。**

```
路径一（默认）：框架驱动 → 检索爆款框架 → 填真实数据 → 出稿
路径二（用户要求时）：AI 原创 → 六维标准 + 开场结尾库 → 出稿
```

**三条链各管一块，绝不混用：**

| 链 | 找什么 | 顺序 |
|---|---|---|
| **数据链** | 价格、面积、学区、容积率 | 本地库 → 联网 → 问用户 |
| **观点链** | 判断标准、方法、金句、行业词 | 知识库 → 爆款库 → 联网 → 自己判断 |
| **人设链** | 城市、名字、从业年限 | 读配置，缺了问一次 |

**最关键的一条：数据链里没有爆款库。** 爆款库的价格学区全是别的城市的，填进去就是污染。

```
路径一（默认）：框架驱动  → 检索爆款框架 → 填真实数据 → 出稿
路径二（用户要求时）：AI 原创  → 用六维标准 + 开场结尾库 → 出稿
```

## ⚠️ 第一条铁律：数据绝不编造

**文案里出现的每一个数字、名称，必须有来源。**

**数据（价格、面积、学区、配套…）** 三级：
```
① 本地楼盘数据库（免费、最准）
② 爆款库搜索（看同行怎么讲这个楼盘/区域）
③ 联网搜索（公开信息）
④ 查不到 → 问用户，不编
```

**观点知识（判断标准、方法论、市场分析…）** 三级：
```
① 知识库（语义检索，最准）
② 爆款库搜索（看同行怎么表达这类观点）
③ 联网搜索（公开资料）
④ 都没有 → 用自己的判断，标明是「一般经验」
```

**三步兜底：**
```
查得到 → 用真实数据
查不到但能搜到 → 用搜索结果（要标「据公开信息」）
都没有 → 留占位，告诉用户「这里需要你补一个数字」
```

**绝对禁止：**
```
❌ 编一个「均价 8500」
❌ 编一个「月销 50 套」
❌ 编一个「划片 XX 小学」
❌ 用「暂无」「待定」「XX」占位后直接交稿
```

# 路径一：框架驱动

## 第 1 步：确认选题

**用户没说清就问一句，说清了别反问。**

```
用户：「帮我写条文案」
你：  「写哪个方向？比如某个楼盘、某个区域、或者某个预算怎么选？」
```

**两类核心选题（用户八成是这两种）：**
- **A. 楼盘分析型** ——「XX 楼盘到底能不能买」
- **B. 预算选房型** ——「预算 X 万，能买哪些 / 该选哪里」

## 第 2 步：检索爆款框架

```python
import json, pathlib, urllib.request

CFG = pathlib.Path.home() / ".fangguagua" / "config.json"
KEY = json.loads(CFG.read_text(encoding="utf-8"))["key"]
GW = "https://www.fangzhinao.com/v1"

def kb(scope, query, top_k=6):
    body = json.dumps({"query": query, "retrieval_model": {
        "search_method": "semantic_search", "top_k": top_k,
        "score_threshold_enabled": False, "reranking_enable": False}},
        ensure_ascii=False).encode("utf-8")
    req = urllib.request.Request(GW + "/kb/" + scope, data=body,
        headers={"Content-Type": "application/json", "x-api-key": KEY}, method="POST")
    with urllib.request.urlopen(req, timeout=45) as r:
        return json.loads(r.read().decode("utf-8", "replace"))
```

**搜什么：**

| 选题 | 检索词 | scope |
|---|---|---|
| 楼盘分析 | `楼盘测评 优缺点` | `framework` |
| 预算选房 | `预算选房 首套怎么选 刚需上车` | `framework` |
| 区域分析 | `区域分析 板块` | `framework` |
| 避坑 | `避坑 套路` | `framework` |
| 人设 | `人设 自我介绍` | `framework` |
| 探盘实拍 | `探盘 带看` | `tanpan` |

**拿到候选后，看 `score`，只要 > 0.5 的。**

## 第 3 步：选一个框架（或多合一）

**三种情况：**

```
① 有 1 条明显最匹配（score > 0.65）→ 直接用
② 有 2~3 条都不错 → 挑一条当骨架，把其他条的好句子/好结构并进来
③ 全都不匹配 → 告诉用户「库里没有正好匹配的框架，要我按自己的方式写吗？」
```

**多合一怎么做：**
```
· 主框架定「结构」（开场方式、观点顺序、结尾类型）
· 其他框架只取「具体表达」（一句好比喻、一个数据呈现方式）
· 不要拼接两套开头 —— 会乱
```

**选好后告诉用户：**
```
「找到 3 个匹配的框架，我用这条当骨架：

 《【城市】×个现房楼盘》（获客型，匹配度 66%）
 结构：盘点式，每个盘讲优点+缺点

 另外两条里的「真话风格」和「评论区互动结尾」我也用上。」
```

## 第 4 步：分析框架要填什么

**拿到框架全文后，逐项拆出来：**

```python
# 框架长这样：
# 【文案框架】【楼盘名字】怎么样？能不能买？
# 【类型】获客型
# 【城市】x月份【楼盘名字】怎么样？能不能买？…
# 均价【价格】，【面积】平，【户型】…
# 优点是【优点】，缺点是【缺点】
# 【结尾钩子】

# 你要拆成：
需要填的数据 = [
    "城市名",      → cfg["city"]
    "楼盘名",      → 用户给 / 数据库
    "均价",        → 数据库 / 搜索
    "户型和面积",  → 数据库 / 搜索
    "优点",        → 数据库 / 分析
    "缺点",        → 数据库 / 分析
]
```

**把清单列给用户看（可选，用户嫌慢就跳过）：**
```
这个框架需要填 6 项数据：
 ✅ 城市：郴州（已知）
 ✅ 楼盘：金域华府（你说了）
 ❓ 均价、户型、学区 —— 我去查
 ❓ 优点、缺点 —— 我根据查到的判断
```

## 第 5 步：数据从哪来（3 级，不碰爆款库）

**「数据」指有具体数值或专有名词的内容：价格、面积、学区、容积率、车位比、交房时间。**

### ① 先查本地数据库（免费、最准）

```python
import sqlite3, pathlib
DB = pathlib.Path.home() / ".fangguagua" / "楼盘数据库.db"
if DB.exists():
    conn = sqlite3.connect(str(DB))
    conn.row_factory = sqlite3.Row
    cur = conn.cursor()
    cur.execute("SELECT * FROM properties WHERE 楼盘名称 LIKE ?", ("%金域华府%",))
    p = cur.fetchone()
    if p:
        print("均价：", p["销售均价范围"])
        print("优势：", p["核心优势"])
        print("问题：", p["潜在问题"])
        print("学区：", p["划片小学"], "/", p["划片初中"])
    conn.close()
```

**查到了直接用，别再搜。**

### ② 没有 → 联网搜索

```
「{城市} {楼盘} 均价 户型 学区」
「{城市} {区域} 房价 2026」
「{城市} 公积金 贷款额度」
```

**搜到后标来源，措辞留余地：**
```
据公开挂牌信息，均价约 8500 元/㎡
```
**不要写「均价 8500」这种斩钉截铁的话 —— 网上数据可能是旧的。**

### ③ 都查不到 → 停下来问用户

```
「金域华府的学区我查不到（网上信息不一致）。
 你知道划片是哪所学校吗？
 不想说的话，文案里我这段就跳过。」
```

**绝对不要编。**

## ⚠️ 为什么数据链里没有爆款库

**爆款库里的价格、学区全是别的城市、别的盘的。**

**实测过：搜「万宝国际城」→ 0 条；搜「万宝」→ 9 条全是福州的。**

**拿它填数据 = 数据污染。所以数据只走上面 3 级。**

## 第 6 步：观点和知识从哪来（4 级，爆款库在这里）

**「观点」指判断、标准、方法、情绪：**

```
· 哪层不能买
· 楼间距多少算窄
· 大盘有什么利弊
· 二手房怎么砍价
· 「怕买完站岗」这种情绪
· 「得房率」「设备层」这种行业词
```

### ① 先查知识库（语义检索，最准）

```python
def kb(scope, query, top_k=6):
    """scope: framework 框架 / copy 成品 / knowledge 干货 / tanpan 探盘"""
    body = json.dumps({"query": query, "retrieval_model": {
        "search_method": "semantic_search", "top_k": top_k,
        "score_threshold_enabled": False, "reranking_enable": False}},
        ensure_ascii=False).encode("utf-8")
    req = urllib.request.Request(GW + "/kb/" + scope, data=body,
        headers={"Content-Type": "application/json", "x-api-key": KEY}, method="POST")
    with urllib.request.urlopen(req, timeout=45) as r:
        return json.loads(r.read().decode("utf-8", "replace"))
```

**查什么：**

| 需要什么 | scope | 例子 |
|---|---|---|
| 方法论、判断标准 | `knowledge` | 「楼层怎么选」「容积率怎么看」 |
| 成品文案怎么写的 | `copy` | 「小区怎么挑」「砍价话术」 |
| 框架结构 | `framework` | 「楼盘测评」「预算选房」 |
| 探盘结构 | `tanpan` | 「带看流程」 |

**⚠️ 知识库是语义检索，可以搜整句：**
```
✅「郴州买房有什么坑」→ 能命中「在【城市】买房，这3个坑千万别踩」
```
**这是它比数据库强的地方。**

### ② 知识库没有 → 搜爆款库（**只用宽泛词**）

**这是实测出来的硬限制：**

| 关键词 | 命中 | 能用吗 |
|---|---|---|
| 二手、避坑、买房、价格 | 5~21 条 | ✅ 能用 |
| 学区、公积金、楼层 | 0~3 条 | ❌ 基本没用 |

**所以爆款库只在这些场景用：**
```
· 探测「这个话题有没有人拍过」（有 → 说明能拍）
· 看同城同行怎么讲宽泛话题
· 找同城的行业黑话、本地标签
```

```python
import urllib.parse

def hot_search(keyword, limit=30, table="bksjk"):
    """table: bksjk=口播 / tpsjk=探盘"""
    q = {"search": keyword, "page_size": limit,
         "is_enabled": 1, "sort": "score_desc"}
    url = GW + "/bksjk/api/sjk/" + table + "?" + urllib.parse.urlencode(q)
    req = urllib.request.Request(url, headers={"x-api-key": KEY})
    with urllib.request.urlopen(req, timeout=45) as r:
        return json.loads(r.read().decode("utf-8", "replace"))

def hot_detail(item_id, table="bksjk"):
    """拿全文（content 是原文，content_framework 是框架）"""
    url = GW + "/bksjk/api/sjk/" + table + "/" + str(item_id)
    req = urllib.request.Request(url, headers={"x-api-key": KEY})
    with urllib.request.urlopen(req, timeout=30) as r:
        return (json.loads(r.read().decode("utf-8", "replace")) or {}).get("row") or {}
```

**⚠️ 搜索是 `LIKE` 关键词匹配，只能用 2~3 字短词：**

```
✅ 楼层 / 公摊 / 公积金 / 二手房 / 避坑
❌ 哪层不能买（0 条）
❌ 郴州买房有什么坑（0 条）
```

**常用映射：**

| 选题 | 搜这些 |
|---|---|
| 哪层不能买 | `楼层` `顶楼` `一楼` |
| 二手房怎么挑 | `二手房` `房龄` |
| 学区房 | `学区` `学位` |
| 避坑 | `避坑` `套路` |
| 砍价 | `砍价` `还价` |
| 房贷 | `公积金` `房贷` |

### 🔑 爆款库最重要的一条规则：**只借表达，不借事实**

**`content` 字段是原文（平均 988 字），里面有两样东西：**

```
✅ 可以借：
   「住得高反而听得越清楚」          ← 金句
   「刚需是个伪概念，是人造的概念」    ← 观点表达
   「得房率」「设备层」「满五唯一」    ← 行业黑话
   先破后立的论证顺序                ← 结构

❌ 绝不能借：
   「深圳均价七万一平」              ← 别的城市的数据
   「2023年10月 8800元/㎡」         ← 过期价格
```

**同城内容可以看数据，但要说清是哪一年：**
```
✅「去年这个时候挂牌大概八千二，今年你去看要问销售」
❌「均价八千二」
```

### ③ 爆款库也没有 → 联网搜索

```
「买房 避开哪些楼层 原因」
「容积率多少算合理」
「二手房 房龄 影响」
```

### ④ 都没有 → 用自己的判断，但标明

```
✅「按一般经验，33 层高层的中高区采光好但等电梯久」
❌「33 层一定不能买中高区」
```

**用「一般」「通常」「多数情况」这类词，别说成定理。**

## 第 7 步：三条链汇合，填进框架

**到这一步手上应该有：**

```
数据（来自本地库/联网）
观点（来自知识库/爆款库/自己）
人设（来自 config：城市、名字、年限）
```

**填进去，然后自检：**

```
□ 所有【占位符】都替换了？（搜一遍有没有【】没填）
□ 每个数字都有来源？
□ 观点有没有「只借表达没借事实」？
□ 开场能自然引出第一个观点？
□ 观点之间有过渡，不是硬拼？
□ 结尾承接最后一个观点？
□ 没有编造的数字/名称？
```

**有占位符没填的，明确告诉用户：**
```
「文案写好了，但「车位配比」这项我查不到，
 我先留了空。你告诉我数字我补上，或者我删掉这句。」
```

## 人设从哪来（第 3 条链）

**这三样每次都要用，不该每次问，也不该每次搜：**

```python
import json, pathlib
CFG = pathlib.Path.home() / ".fangguagua" / "config.json"
cfg = json.loads(CFG.read_text(encoding="utf-8"))

# 缺了才问，问完存起来
for k, ask in [("city", "你在哪个城市？"),
               ("name", "你的名字/称呼是什么？"),
               ("years", "你做房产几年了？")]:
    if not cfg.get(k):
        cfg[k] = input(ask)
        CFG.write_text(json.dumps(cfg, ensure_ascii=False), encoding="utf-8")
```

**这三样在文案里的位置：**
```
城市 → 开场和正文到处用
名字 → 结尾「我是【名字】」
年限 → 结尾「我做这行【X】年」
```

# 路径二：AI 原创（用户明确要求时）

## 第 1 步：数据准备（不可跳过）

**跟路径一的第 5 步完全一样：**
```
① 本地楼盘数据库
② 联网搜索
③ 问用户，留空不编
```

**观点和知识走第 6 步的 4 级链（知识库 → 爆款库 → 联网 → 自己判断）。**

**这一步不做完，不许开始写。**

## 第 2 步：判断文体

| 文体 | 用在哪 |
|---|---|
| **抖音口播** | 视频文案。纯口语，数字用汉字，无 emoji |
| **朋友圈** | 短文案 + 配图 |
| **小红书** | 标题 + 正文 + 标签 |

## 第 3 步：按六维标准写

**每篇文案必须同时满足这六条，缺一条就是不合格：**

| 维度 | 标准 | 要什么 | 禁止 |
|---|---|---|---|
| **共鸣感** | 引发情感共鸣 | 常见痛点、焦虑、困扰 | 平淡的事实陈述 |
| **认同感** | 获得用户认同 | 揭示普遍认知、常识真相 | 小众反常识观点 |
| **价值感** | 提供实际价值 | 解决方案、避坑方法、省钱技巧 | 单纯描述现象 |
| **专业感** | 体现专业权威 | 数据支持、逻辑分析、深度见解 | 主观判断、无依据 |
| **行动感** | 引导用户行动 | 具体建议、明确行动指令 | 抽象概念 |
| **收获感** | 带来信息收获 | 具体房源、具体楼盘、新知识、新视角 | 常识性内容 |

**写完全篇再对照这六条检查一遍。**

## 第 4 步（抖音口播专用）：开场 + 结尾

### 严禁这三种开场

```
❌「【城市】的朋友/老乡/业主们，注意了！」

### 开场示例库（8 种，选一个改造）

**痛点/疑问类**
```
「今年在【城市】买房，怕买完站岗；不买，又怕以后更买不起。对吗？
 这是最近粉丝问我最多的问题。我干了【X】年销售，今天说点扎心的大实话。」
```

**反共识/敢说类**
```
「【城市】的房子还能买吗？我想说点中介不敢说的话。

```

**警告/避坑类**
```
「不管你在【城市】买新房还是二手，以下【X】种房子，碰都别碰！

```

**秘密/内幕类**
```
「就算我明天不在【城市】干房产了，今天也必须告诉你，
 销售绝不会跟你说的【X】个秘密。视频过于真实，肯定被下架，赶紧收藏。」
```

**攻略/选择类**
```
「预算【X】到【X】万，在【城市】怎么买房不踩坑？

```

**楼盘评测类**
```

 看完这条视频，你会全面了解它的所有优缺点，以及里面哪些楼栋户型能买，哪些是坑。」
```

**区域分析类**
```
「【城市】各个区都有哪些致命缺点？我敢说百分之九十九的购房者都不知道。

**现房/推荐类**
```

```

### 正文结构

```
[开场：从上面 8 种选一个，填真实数据]

[中间：3~5 个核心观点]
每个观点必须：
  · 有具体数据或案例支撑
  · 口语化，句子短
  · 多用「你」「我」
  · 观点之间自然过渡（「还有一个事」「更关键的是」）

[结尾：从下面 3 种选一个]
```

### 结尾示例库（3 种）

**⚠️ 核心原则：只营造真诚、有温度的知识分享，不催关注、不催私信、不催点赞。目的是让用户记住主播、完成信任塑造。**

**A · 真诚祝愿型**

 如果你对买房还有很多疑惑，或者怕买贵、怕选错、怕被坑，那不妨找我聊聊。

 我都希望你能把你的需求情况跟我讲清楚 ——
 你的预算、能承受的月供、目前看好的区域、配套的要求、户型的要求，都可以跟我沟通。
 我觉得适合你的房子会带你看，我觉得不能买的房子，即便你要去看，我也会阻止你。
 这是我的态度跟原则。我做这行【X】年了，每个人的情况都不一样，
 房子还是要多看多对比，才能看到满意心仪的。看完后，我期待你的回复。」

**C · 专业承诺型**

## 错误处理

| 情况 | 怎么做 |
|---|---|
| 没配密钥 | 「请先把密钥发给我」 |
| 用户没说选题 | 问一句「哪个楼盘/区域/预算段？」 |
| 框架检索 0 条 | 「库里没有正好匹配的，要我按自己的方式写吗？」 |
| 数据查不到 | **停下来问用户，不编** |
| 搜索结果冲突 | 取最新，措辞用「大概」「约」 |
| 用户嫌文案太长 | 问「压到多少字？1 分钟的话大概 250 字」 |
| 用户说「不像我说话」 | 问「你平时怎么讲？给我一句你的原话，我按那个调」 |

## 十条铁律

```
① 数据绝不编 —— 查不到就问，宁可留空
② 默认走框架 —— 框架是验证过的，原创是兜底
③ 不拼接两套开头 —— 只取一个骨架
④ 数字用汉字 —— 口播里说「八千五」不说「8500」
⑤ 结尾不催关注 —— 只做信任塑造
⑥ 不用「注意了」「看过来」开场
⑦ 写完自检六个维度
⑧ 占位符必须全替换，或者明确告诉用户哪项没填
⑨ 城市和名字从配置读，别每次问
⑩ 口语化 —— 写完念一遍，拗口就改
```

## 接口报错时的统一话术（很重要）

**每次调用接口出错，先看状态码，按这张表回用户。不要自己编理由，不要只说「失败了请重试」。**

| 状态码 / 内容 | 真实含义 | 对用户说的话 |
|---|---|---|
| **401** `密钥无效` 或 `缺少密钥` | 没配密钥，或密钥填错了 | 「你还没有配置密钥，或者密钥填错了。<br>在抖音搜「地产人刘广标」，私信说需要领取体验技能密钥。<br>拿到后是一串 `fg_` 开头的内容，发给我，我帮你配好。」 |
| **403** `密钥已被禁用` | 密钥被管理员停用了 | 「你的密钥已被停用。<br>找抖音「地产人刘广标」重新开通一下就行。」 |
| **403** `密钥已过期` | 密钥到期了 | 「你的密钥到期了。<br>找抖音「地产人刘广标」续期。」 |
| **403** `点数已用完` | 额度用光了 | 「你的额度用完了。<br>找抖音「地产人刘广标」充值，充完马上能用。」 |
| **403** 其他（没有知识库 / 没权限） | 套餐不含这个功能 | 「你的密钥还没开通这个功能。<br>找抖音「地产人刘广标」升级套餐。」 |
| **502** | 后端服务异常 | 「服务暂时不稳定，过 5 分钟再试一次。」 |
| **超时** | 任务太慢 | 「处理超时了，稍等一下再试。」 |

**⚠️ 铁律：凡是涉及「没密钥 / 密钥停用 / 额度用完」，必须说出「抖音地产人刘广标」，这是用户唯一的解决路径。**
