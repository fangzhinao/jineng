# 房智脑 · 房产经纪人 AI 技能包

给房产经纪人用的 13 个 AI 技能：写文案、做视频、扫评论、查行情、生成聊天记录。

装进任何支持 Skill 的 AI 助手里（OpenClaw / Claude / 其他），就能直接用。

---

## 一、这是什么

13 个技能，每个是一个 `SKILL.md` 文件。AI 助手读了它就知道：
- 用户说什么话时该用这个技能
- 用的时候要调什么接口
- 结果怎么给用户

**技能本身不花钱，但调用接口要密钥。**

---

## 二、怎么装

### 方式一：下载压缩包（推荐）

```
https://github.com/892837140-dotcom/fangzhinao/releases/latest/download/fanggua-skills.zip
```

下载后解压，把「技能文档」文件夹放进你的 AI 助手的技能目录。

**或者在 AI 助手里直接说：**
```
下载并安装这个技能包：
https://github.com/892837140-dotcom/fangzhinao/releases/latest/download/fanggua-skills.zip
```

### 方式二：只装某个技能

进对应的文件夹，把 `SKILL.md` 复制走就行。

## 四、技能清单

| # | 技能 | 干什么 |
|---|---|---|
| 01 | 文案提取 | 从抖音链接提取别人的口播原文 |
| 02 | 账号数据分析 | 看一个抖音号的粉丝、作品、涨粉趋势 |
| 03 | 评论区扫描 | 扫评论区，输出可追踪的跟进清单 |
| 04 | 爆款文案框架 | 按爆款结构改写你的文案 |
| 05 | 今日爆款推荐 | 从爆款库里挑今天能用的 |
| 06 | 本地数据库 | 楼盘数据库查询和建库 |
| 07 | 文生图 | 生成封面图、配图 |
| 08 | 知识库 | 上传你的专业资料，让 AI 记住 |
| 09 | 聊天记录生成 | 生成客户对话截图（成交案例素材） |
| 10 | 创作灵感 | 根据你的城市和行业出选题 |
| 11 | 写作 | 完整写作流程（框架 / 原创两种路径） |
| 12 | 深度解读视频 | 长文案自动生成解读视频 |
| 14 | 抖音自动发布 | 自动发视频到抖音（本地运行） |

**（13 号是内部安装教程，不公开）**

---

## 五、技能 06 和 14 要额外说明

**06-本地数据库** 要用 SQLite 浏览器查看数据，安装包不放在这里（太大），
技能文档里写了 OSS 下载链接，点进去下就行。

**14-抖音自动发布** 跟其他技能不一样：
- 其他技能跑在云端接口
- 这个跑在**你自己的 Windows 电脑**上，要装 Python + 浏览器环境
- 详细步骤见技能文档

## 七、遇到问题

- 接口报 401 → 密钥没配好，问一下刘广标
- 接口报 403 → 密钥没权限用这个技能，找刘广标开通
- 接口报额度不足 → 体验额度用完了，找刘广标开通正式版
- 技能不触发 → 检查 `SKILL.md` 的 `description` 里有没有描述你会说的话
