# 房智脑 · 房产经纪人 AI 技能包

给房产经纪人用的 13 个 AI 技能：写文案、做视频、扫评论、查行情、生成聊天记录。

装进任何支持 Skill 的 AI 助手里（OpenClaw / Claude / 其他），就能直接用。

---

## ⚠️ 装好之后第一件事：领体验密钥

**技能装好了还不能用，需要一把密钥。**

**在抖音搜「地产人刘广标」，私信说：**

```
你好，我装好了房智脑技能包，想领一个体验密钥
```

**他会发你一串 `fg_` 开头的密钥，你发给 AI 助手，说「帮我配置密钥」，就配好了。**

**装完不领密钥，AI 会提示「你还没有配置密钥」—— 这正常，去领就行。**

## 一、这是什么

13 个技能，每个是一个 `SKILL.md` 文件。AI 助手读了它就知道：
- 用户说什么话时该用这个技能
- 用的时候要调什么接口
- 结果怎么给用户

**技能文件是免费的，用的时候需要一把密钥（可以找刘广标领体验的）。**

## 三、怎么让 AI 写得更好（重要）

**13 个技能只是工具，写得出来写不出来，取决于你给它喂了多少真东西。**

```
你的库里有什么        AI 能写什么
──────────────────────────────────────────
什么都没有            空话：「XX 板块值得关注」
楼盘数据齐全          实的：「金域华府 89 平三房，均价 8500，首付 23 万」
有成交案例           有故事的：「上个月帮客户 87 万拿下 XX 小区」
有行业干货           讲得清的：「公积金贷款额度这样算」
──────────────────────────────────────────
库越全，写出来越像你，越不敢瞎编
```

### 建议按这个顺序准备

**第一步：把楼盘、房源数据发给我**

```
把你手上有的资料直接发给 AI：
· 楼盘清单（Excel、Word、微信聊天截图都行）
· 房源信息（小区名、面积、价格、楼层、朝向）
· 在售楼盘的价格表

AI 会帮你整理成结构化数据，存进你的数据库和知识库。
```

**第二步：把你的专业干货存进知识库**

```
你觉得讲得好的内容，都可以存：
· 你自己发过的爆款视频文案
· 你总结的行业经验、话术
· 客户常问的问题和你的标准回答
· 政策解读（公积金、限购、税费）

存进去之后，AI 写文案时会引用，不会自己瞎编。
```

**第三步：把好账号发给我，我帮你提取**

```
你觉得哪个同行讲得好？把抖音账号发过来：
· 「帮我看看这个号，提取他的精选内容」
· 「这个号讲学区讲得好，把精华弄进我的库」

AI 会抓他的作品文案，整理成你库里的参考资料。
（只借表达方式和选题角度，不抄事实数据）
```

## 五、技能 06 和 14 要额外说明

**06-本地数据库** 要用 SQLite 浏览器查看数据，安装包不放在这里（太大），
技能文档里写了 OSS 下载链接，点进去下就行。

**14-抖音自动发布** 跟其他技能不一样：
- 其他技能跑在云端接口
- 这个跑在**你自己的 Windows 电脑**上，要装 Python + 浏览器环境
- 详细步骤见技能文档

## 七、遇到问题

- 接口报 401 → 密钥没配好，问一下刘广标
- 接口报 403 → 密钥没权限用这个技能，找刘广标开通
- 接口报额度不足 → 体验额度用完了，找刘广标开通正式版
- 技能不触发 → 检查 `SKILL.md` 的 `description` 里有没有描述你会说的话
