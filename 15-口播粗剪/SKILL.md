## 🔴 先说清楚：这是粗剪，不是精剪

**这个技能只做两件事：删停顿、删废镜头。做完之后你还要自己精剪。**

```
✅ 它帮你做的：
   · 把 20 分钟的素材压到 10 分钟
   · 把讲错的废镜头挑出去
   · 省掉你 80% 的拖时间轴时间

❌ 它不做的：
   · 不加字幕
   · 不加 BGM
   · 不调色
   · 不加转场、特效、贴纸
   · 不调整内容顺序
   · 不剪成竖屏/横屏（保持原样）

所以：剪完之后还是要拿剪映过一遍，加字幕、配乐、精修。
      但你已经不用再花一小时找"哪里讲错了"。
```

**一句话：它把「挑素材」这件事干掉，你只做「包装」。**

## 两种模式（用的时候告我要哪个）

### 模式一：只剪气口

**做什么：** 只把说话之间的停顿、空白剪掉，内容一刀不动。

```
适合：
· 你一次录完，没什么讲错
· 想保留完整内容，只要节奏紧一点
· 最安全，不会删错任何内容

效果：20 分钟 → 15 分钟左右
```

**怎么用：**
```
「帮我剪气口就行」
「只剪停顿，别删内容」
```

### 模式二：AI 剪辑（剪气口 + 去重拍）

**做什么：** 先剪气口，再自动找出你讲错重说的那段，删掉前面的废版本。

```
适合：
· 录的时候有讲错、重来
· 一段话说了好几遍才对
· 想剪得干净一点

效果：20 分钟 → 8-10 分钟
```

**怎么用：**
```
「AI 剪辑」
「剪气口 + 去重拍」
```

### 怎么选

```
你不确定 → 先跑「只剪气口」，安全
你录的时候喊过「重拍」 → 用「AI 剪辑」
```

### AI 剪辑会自动判断（不用你操心）

**模式二内部有两条路，自动选：**

```
① 你喊过「重拍」
   → 精确定位重说范围，删得最准

② 你没喊「重拍」
   → AI 通读全文，找「说错重起」和「说好几遍」的地方
   → 找到就删，找不到就只剪气口

所以你不用管自己有没有喊过，选「AI 剪辑」就行。
```

## 第三步：查进度（必须轮询）

**提交后返回 `job_id`，然后每 10-20 秒查一次：**

```python
import urllib.request, json, time

def query(job_id, key):
    req = urllib.request.Request(
        "https://www.fangzhinao.com/v1/koubo/job/" + job_id,
        headers={"x-api-key": key})
    with urllib.request.urlopen(req, timeout=30) as r:
        return json.loads(r.read().decode())

# 轮询
for i in range(60):
    d = query(job_id, KEY)
    st = d.get("status")
    print("%s%%  %s" % (d.get("progress", 0), d.get("step", "")))
    if st == "done":
        print("成片:", d["result"]["video_url"])
        break
    if st == "failed":
        print("失败:", d.get("error"))
        break
    time.sleep(15)
```

## 🔴 录制建议（模式二最重要）

**模式二靠你说「重拍」来定位废镜头。所以录制时请这样：**

```
讲错了不要补词，直接说一句「重拍」，然后把那句话从头完整讲一遍。
```

### ✅ 正确

```
「郴州首付大概十八万……重拍……郴州现在首付大概二十万左右」
                          ↑
                    我在这里切，后面全保留
```

### ❌ 别这样

```
「郴州首付大概十八万……不对，应该是二十万」
                      ↑
              补词的话我分不清哪句该删
```

### 不用每次都喊

**如果整条视频一次录完没讲错，不用喊「重拍」，直接用模式一。**

## 能识别哪些词（模式二）

```
重拍 / 重来一遍 / 拍错了 / 讲错了 / 重新拍
```

**⚠️ 正常的「从来不是」「你重来一次」不会误判。**

## 常见问题

**Q：剪完能直接发抖音吗？**
A：不行。这是粗剪，你还要加字幕、配乐、精修。它的作用是帮你省掉挑素材的时间。

**Q：成片链接多久失效？**
A：7 天。要长期保存请下载到本地。

**Q：能剪横屏吗？**
A：能，横竖屏都支持，输出保持原分辨率。

**Q：会掉画质吗？**
A：不掉，保持原码率（约 9 Mbps）。

**Q：能加字幕吗？**
A：这个技能不做字幕。剪完拿剪映加，或者用「08-知识库」生成文案。

**Q：视频很大传不上去？**
A：先用剪映或手机相册压一下（1080p 就够），压到 200 MB 以内最快。

**Q：画质会掉吗？**
A：不会。输出码率按原片的 90% 走，最低 4 Mbps，最高 15 Mbps。原来 15 Mbps 的片子出来还是 12-13 Mbps。

**Q：为什么只剪了这么点？**
A：说明你的素材本来就干净。剪气口只删真正的停顿，不会硬凑时长。

## 技术说明（给想了解的人）

```
模式一流程（不转写、不调 AI，最快）：
  剪气口（silencedetect 找静音 + ffmpeg 精确切割，自动选阈值）

模式二流程：
① 剪气口（silencedetect + ffmpeg 精确切割）
② 在剪完气口的视频上转写（faster-whisper，词级时间戳）
③ 找「重拍」等锚点词
④ 合并连续锚点 → 重拍事件
⑤ AI 逐个事件判断「重说范围」（DeepSeek）
⑥ 按时间轴剪切
```

**为什么先剪气口再转写：**
```
剪完气口，长静音没了，转写更准，句子更连贯
而且只有一套时间轴，不会错位
```
